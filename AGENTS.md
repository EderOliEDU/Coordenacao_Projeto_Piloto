# Publicações em Produção

- Por instrução do responsável: antes de qualquer atualização de Produção, publicar primeiro no GitHub e conferir o SHA da main. Não publicar código local que ainda não foi enviado ao GitHub.
- Validar no DEV antes da publicação. Preservar respostas e dados de Produção; não copiar dados do DEV. Aplicar apenas migrações necessárias à versão e manter backups próprios de Produção.
- O usuário ederoli deve usar o acesso permanente limitado a atualizações, sem liberar sudo geral. Procedimento em `docs/acesso-atualizacoes-producao.md`.
